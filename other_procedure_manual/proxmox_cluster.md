# クラスタ構築・参加手順

## クラスタ構築時の最低条件

1. 最低3台の奇数ノード構成にすること。Quorum判定で過半数を超えられず、ノードがクラスタに復帰出来ない場合があるため。
2. 時刻・時間が同期されていること。
3. rootユーザーのパスワードが設定されていること。
4. UDP5404番ポート・UDP5405番ポートで通信が行えること(for corosync to work)。
5. TCP22番ポートで通信が行えること(ノード間のSSH)。
6. レイテンシが2ms以下であること。
7. ノード間で異なるファイルシステムを利用してはいけない。クラスタが組めないため。
8. VMIDが被ってはいけない。クラスタが組めないため。
9. クラスタに参加するノード上にVMが存在していてはいけない。(プライマリであればOK)

## クラスタ新規構築

1. Primaryにしたいノードの「データセンター」のクラスタ欄から「Create Cluster」を選択し、クラスタ名を記載する。

    ![スクリーンショット 2025-02-07
141526.png](attachment:5f35d8b7-3326-499c-8930-dde30b321e92:スクリーンショット_2025-02-07_141526.png)

    - Primaryにしたいノードに特別な役割・意味はなく、クラスタのIDが1なだけです。
    - クラスタ名は変更することができないので気をつけてください。
2. 「Create」をクリックするとViewerでログが流れ、「TASK OK」と表示したら作成完了です。
3. 一度ログアウトしログインしてください。
4. Datacenter(クラスタ名)が表示したら構築完了になります。

## クラスタ参加方法

1. 入りたいクラスタの「データセンター」（dev-pve-cluster）のクラスタ欄から「Join Information」をコピーする。

    ![スクリーンショット 2025-02-07
135123.png](attachment:631efbcb-4a32-4c5d-85e8-55d9cd6356ac:スクリーンショット_2025-02-07_135123.png)

2. クラスタの参加は、参加するノードの「データセンター」クラスタ欄から「Join Cluster」を選択し、コピーしたJoin情報を貼り付ける。

    ![スクリーンショット 2025-02-07
135214.png](attachment:cc2f040f-6560-4f57-b966-62b0d4fc32ad:スクリーンショット_2025-02-07_135214.png)

3. 「Join」をクリックすると、Primaryノードのrootパスポートを要求されるので入力する。
4. クラスタに参加するとエラーは発生し強制的にログアウトするので、もう一度ログインする。
    - エラー原因は、クラスタ参加後にノード側のSSL鍵を再作成するためです。
5. データセンターにdev-pve-clusterが表示されていて、ノードに緑のチェックがあればクラスタ参加成功です。

## ノード間マイグレーション

1. ノードのポップアップオプションから「Migrate」を選択する。

    ![スクリーンショット 2025-02-07
142556.png](attachment:0c9d1a08-79d0-4675-ac8b-ee15edca1571:スクリーンショット_2025-02-07_142556.png)

2. 「Target node」で移動先のノードを選択し、「Target storage」で移動先ストレージを選択する。

    ![スクリーンショット 2025-02-07
142608.png](attachment:cc4a624f-7939-477b-8afb-7045426d9a14:スクリーンショット_2025-02-07_142608.png)

3. 選択後、「Migrate」をクリックする。
4. Viewerでログが流れ、「TASK OK」と表示したらマイグレーション完了です。

    ![スクリーンショット 2025-02-07
152032.png](attachment:92591270-2687-4beb-9019-cde022025751:スクリーンショット_2025-02-07_152032.png)

    - dev-pve0x（local-lvm）からdev-pve0x（local-lvm）の場合、所要時間は5~10分。
    - dev-pve0x（local-lvm）からdev-pve0x（nas0x）の場合、所要時間は5~10分。
    - dev-pve0x（nas0x）からdev-pve0x（nas0x）の場合、所要時間は30秒。


## クラスタの設定ファイル

- クラスタの設定はファイルは以下に格納されている。
- クラスタからノードを削除しても、ここのファイルは削除されないので注意する。

```bash
root@dev-pve01:~# ls -l /etc/pve/nodes/
total 0
drwxr-xr-x 2 root www-data 0 Dec 29 14:53 dev-pve01
drwxr-xr-x 2 root www-data 0 Jan 23 19:22 dev-pve02
drwxr-xr-x 2 root www-data 0 Jan 30 14:31 dev-pve03
```
